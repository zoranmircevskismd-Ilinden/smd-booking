- Edit existing event
- Better filtering by user / object / vehicle

## Medium priority
- Cleaner split of HTML / CSS / JS into separate files
- Better validation for overlapping bookings
- Better mobile UX polish

- Audit log / change history

- More advanced admin controls

- `index.html`
- `app.css`
- `app.js`
- `config.js`
